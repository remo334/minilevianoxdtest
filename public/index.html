How to connect the code

Six quick steps from number to linked bot.

  1. Enter your full WhatsApp number with the country code, for example 917907997537.
  2. Tap Generate pairing code and wait for the 8-character code.
  3. Tap the code or press Copy to copy it.
  4. Open WhatsApp, then Settings → Linked devices.
  5. Choose Link with phone number instead.
  6. Paste the code. Your bot connects and sends you a confirmation message.
